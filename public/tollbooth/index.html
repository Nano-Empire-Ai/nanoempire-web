1-Minute Python Quickstart

Install the official SDK directly from PyPI:

pip install nano-empire-tollbooth

Protect any FastAPI or Flask route with one decorator:

from fastapi import FastAPI
from nano_empire_tollbooth import TollboothGate

app = FastAPI()
gate = TollboothGate(price_usdc=0.05, network="base")

@app.get("/api/v1/compute")
@gate.protect()
async def compute_payload():
    return {"status": "computed", "data": [1, 2, 3]}
